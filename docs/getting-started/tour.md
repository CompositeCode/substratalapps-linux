# Find your way around
{: .no_toc }

## The sidebar

The sidebar has up to three sections. You only see what you can use.

- **Personal**: Home, Inbox, Organizations, Account, Plan & Billing, Settings. Everyone has these.
- **Administration**: Users, Access, Roles, Audit Log, Send notification. Staff, and app owners (Access only, for their own apps).
- **Developer**: Applications, API Keys, Webhooks, Tenant. App owners and staff with developer permissions.

[Navigation and permissions]({{ '/reference/navigation/' | relative_url }}) lists exactly who sees what. On a narrow window (under 600 sp, like a Linux phone) the sidebar becomes its own page; tap back to return to it.

## Get anywhere with the keyboard

- <kbd>Ctrl+K</kbd> opens the **command palette**: type part of a screen's name, its ID (like `KEY-01`) or its route, then press <kbd>Enter</kbd>.
- <kbd>Alt+1</kbd>…<kbd>Alt+6</kbd> jump to the Personal destinations.
- <kbd>F1</kbd> opens help for the screen you're on.

All shortcuts are in [Keyboard shortcuts]({{ '/reference/shortcuts/' | relative_url }}), and <kbd>Ctrl+?</kbd> shows them in the app.

## Links into the app

Links like `substratal://admin/users` open the matching screen in the running app. Every screen's help page shows its link.

## Banners at the top

| Banner | Meaning |
|---|---|
| You're offline | Showing what was already loaded; changes are paused until you reconnect. |
| A newer version is available | This app's API version is deprecated and will stop working on the date shown. Update soon. |
| Connected to …, not production | The app is pointed at a test environment. |
