# Guides
{: .no_toc }

How each area of the Hub works and how its pieces fit together. For step-by-step tasks, see [Tutorials]({{ '/tutorials/' | relative_url }}).
{: .fs-6 .fw-300 }

Three ideas run through every area:

1. **Is the app on for this person?** Each person has an access status per app: Active, Scheduled, Disabled, Expired, Revoked or None. The access switch turns it on and off.
2. **If it's on, what can they do?** Roles grant permissions.
3. **Where does access come from?** Several paths can give one person access to one app: platform-managed ones (`free` apps, and a Standard `subscription`) and grants (`purchase`, `trial`, `admin_grant`, `org_seat`). The Hub shows the resolved status first and the paths one click away. Platform-managed access can only be turned off and back on, never edited or deleted.
